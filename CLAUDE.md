# Doodle Den

Kids creative app (Expo SDK 57, React Native, TypeScript strict). The build spec lives in `docs/spec/`.

- Read `docs/spec/A1-agent-rules-setup.md` before writing code; its rules are mandatory.
- Work one ticket at a time, in the order of `docs/spec/A6-task-tickets.md`.
- Mockups for look and feel: `design/project/*.dc.html`.
- After each ticket: `npx tsc --noEmit && npx expo lint && npx jest`, then update `docs/PROGRESS.md`.
- Install packages only with `npx expo install`, and only those on the A1 allowed list.
